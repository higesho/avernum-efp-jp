Avernum: Escape From the Pit 日本語化パッチ __VERSION__
==========================================================

Spiderweb Software の RPG「Avernum: Escape From the Pit」（Steam 版）を日本語で遊べるようにする非公式パッチです。
会話・本・クエスト・アイテム名・画面の文字・看板・地図など、ゲーム内のほぼすべての文章を日本語にします。

紹介ページ: __PAGE_URL__


■ 対応しているゲーム
  Steam 版 Avernum: Escape From the Pit（アプリ番号 208400）
  GOG 版や Humble 版、旧 Mac/iPad 版には対応していません（インストーラーが確認して中止します）。


■ インストール
  1. ゲームを終了しておきます。
  2. この ZIP を好きな場所に展開し、install.bat をダブルクリックします。
     ・ゲームのフォルダは Steam の設定から自動で探します。見つからないときは、Avernum.exe のある
       フォルダのパスを入力してください（Steam の「管理」→「ローカルファイルを閲覧」で開けます）。
     ・「Windows によって PC が保護されました」と出た場合は「詳細情報」→「実行」を押してください。
  3. 「インストールしました」と出たら完了です。Steam からゲームを起動してください。

  このパッチには元のゲームのファイルは入っていません。お手元のゲームのファイルに差分を当てて日本語版を作ります。
  元のファイルはゲームフォルダ内の「_jp_backup」フォルダに保存されます。


■ アンインストール（元に戻す）
  uninstall.bat をダブルクリックします。
  または Steam でゲームを右クリック →「プロパティ」→「インストール済みファイル」→「ゲームファイルの整合性を確認」を
  実行し、ゲームフォルダの dsound.dll / avernum_jp.ini / avernum_jp_exe.tsv を削除しても元に戻ります。


■ 設定
  ゲームフォルダの avernum_jp.ini で、日本語フォント（既定: メイリオ太字）・文字の濃さ・大きさ・位置などを変えられます。
  再インストールしても、すでにある avernum_jp.ini は上書きしません。


■ 注意
  ・ゲームの更新で Avernum.exe が変わると、日本語表示が動かなくなることがあります。
  ・英語版で作ったセーブデータを読み込むと、セーブに記録済みの文字（メモやログなど）は英語のまま表示されることがあります。
    新しく始めるのがおすすめです。
  ・翻訳は AI（Claude）による翻訳を、用語集と口調メモでそろえて手直ししたものです。
    誤訳や不自然な箇所、表示の崩れがあれば GitHub の Issues でお知らせください。
  ・ベータ版です。全編を通したプレイでの確認はまだ済んでいません。


■ 仕組み
  ・dsound.dll（DirectSound の代理 DLL）がゲーム起動時に読み込まれ、文字描画を日本語対応のものに置き換えます。
  ・スクリプト・シナリオデータ・画像はインストール時に日本語版に書き換えます。
  ・ソースコードと翻訳ツールは紹介ページからたどれる GitHub リポジトリで公開しています。
